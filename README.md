# Buddy Pet Mod

A Minecraft Fabric mod that adds a cute pet companion!

## Features (Sprint 1)
- **Buddy** - A friendly pet that follows you around
- Tame it with **cookies**
- Right-click to make it sit/stand
- Cute blue and pink appearance

## Requirements
- Minecraft Java Edition 1.20.4
- Fabric Loader 0.15.6+
- Fabric API
- Java 17+

## Building
```bash
./gradlew build
```

The mod JAR will be in `build/libs/`

## Testing
```bash
./gradlew runClient
```

## How to Use
1. Get the mod JAR into your `mods` folder
2. Start Minecraft with Fabric
3. Find the "Buddy Spawn Egg" in the Spawn Eggs creative tab
4. Spawn your buddy!
5. Give it a cookie to tame it
6. Right-click to toggle sitting
